# VK → Telegram Bot

Автоматическая пересылка постов из ВКонтакте в Telegram-каналы с поддержкой всех типов медиа, проверкой рекламы, авто-обновлением аватарок и интерактивным управлением.

## 🚀 Возможности

### Основное
- ✅ **Автопересылка** постов VK → Telegram, мониторинг нескольких пар
- 📸 **Все типы медиа**: фото, видео, аудио, документы, GIF, статьи, плейлисты
- 🧩 **Контент одним сообщением, где возможно**: альбом фото+видео с подписью, **GIF + текст в одном сообщении**, **несколько аудио одним альбомом**
- 🎨 **Авто-обновление аватарок** каналов (по хэшу) + ручное `/avatar`
- 🔐 **Роли и доступ**: главный админ, временные админы по инвайт-кодам (24 ч), блокировка пользователей
- 🛡️ **Проверка рекламы** в первых комментариях для «небезопасных» пар
- 📝 **Верификация канала** при создании пары
- 🗣️ **Жалобы** пользователей (`/report`)

### UX
- 🧷 **Интерактивный ввод**: если у команды не указан обязательный параметр, бот попросит ввести его (или `/cancel`) — удобно для управления кнопками
- ⌨️ **Короткие алиасы** команд (`/con`, `/ls`, `/on`, `/off`, `/del`, …)
- 📊 **Аккуратные ответы** — сводки и таблицы в моноширинных блоках
- 👤 **@username вместо ID** в ответах, где никнейм известен

### Технические
- ⚡ **Rate limiting**: пер-канальный лимит Telegram + очередь запросов VK
- 🔁 **Retry + обработка FloodWait** с эскалацией задержек
- 💾 **БД SQLite (Tortoise ORM)** + write-back кэш `last_post_id`
- 🐳 **Локальный Bot API** — файлы до 2 ГБ
- 🧹 **Автоочистка** временных файлов, ротация логов
- 🔒 **`verify_ssl`** — переключатель проверки TLS (для тестов)
- 🧱 **Единые экземпляры сервисов** (общий кэш у монитора и обработчиков)

- Python 3.11+

## 🔧 Установка

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

pip install -r requirements.txt

cp .env.example .env   # заполнить токены
python main.py
```

Локальный Bot API (для файлов до 2 ГБ), пример через Docker:
```bash
docker run -d -p 8081:8081 --name telegram-bot-api \
  -e TELEGRAM_API_ID=YOUR_API_ID -e TELEGRAM_API_HASH=YOUR_API_HASH \
  aiogram/telegram-bot-api:latest
```
В `.env`: `USE_LOCAL_API=true`, `TG_API_SERVER=http://127.0.0.1:8081`.

## ⚙️ Конфигурация

Секреты и параметры окружения — в `.env`. Прочие настройки (интервалы, лимиты, кэши, log level и т.д.) имеют значения по умолчанию в `config.py` и **не обязательны** в `.env`, но при необходимости переопределяются переменной окружения.

### Обязательные переменные `.env`

```env
# Telegram
BOT_TOKEN=123456:ABC...
USE_LOCAL_API=false                 # true — локальный Bot API (до 2 ГБ)
TG_API_SERVER=http://127.0.0.1:8081
ERROR_CHANNEL_ID=-1001234567890     # канал для ошибок и системных уведомлений
REPORT_CHANNEL_ID=-1009876543210    # канал для жалоб /report

# VK
VK_TOKEN=vk1.a.your_service_token

# Доступ
ADMIN_USER_ID=123456789             # постоянный администратор

# Прочее
WEB_AUTH_TOKEN=your_secret          # зарезервировано
```

### Необязательные (дефолты в `config.py`)

```env
# MONITOR_INTERVAL=60               # интервал опроса VK, сек
# CACHE_FLUSH_INTERVAL=10           # сброс write-back кэша в БД, сек
# AVATAR_UPDATE_INTERVAL_HOURS=24
# AVATAR_CHECK_ON_MONITOR_CYCLES=60
# LOG_LEVEL=INFO                    # DEBUG/INFO/WARNING/ERROR
# REPORT_RATE_LIMIT_PER_HOUR=5
# WEB_PORT=8080
# VERIFY_SSL=true                   # false — отключить проверку TLS (только для тестов)
```

Полный перечень настраиваемых параметров — в [`config.py`](config.py) (лимиты Telegram/VK, размеры кэшей, семафоры загрузок, пагинация, таймауты yt-dlp и т.д.).

## 🤖 Команды

У большинства команд есть короткий алиас (в скобках). Если обязательный параметр не передан — бот **спросит** его (см. [ниже](#-интерактивный-ввод-параметров)).

### Авторизация
| Команда | Описание |
|---|---|
| `/login` | Авторизация по инвайт-коду |

### Управление парами
| Команда | Алиас | Описание |
|---|---|---|
| `/connect <vk> [is_safe] [name] [pair_id]` | `/con` | Подключить VK-группу к каналу (с верификацией) |
| `/pairs [page]` | `/ls` | Список пар (таблица, пагинация) |
| `/enable <pair_id>` | `/on` | Запустить пересылку |
| `/disable <pair_id>` | `/off` | Остановить пересылку |
| `/delete <pair_id\|name>` | `/del` | Удалить пару |
| `/avatar <pair_id>` | `/av` | Обновить аватарку канала из VK |

### Действия
| Команда | Алиас | Описание |
|---|---|---|
| `/backfill <pair_id> [count]` | `/bf` | Переслать последние N постов (по умолч. 100) |
| `/broadcast <text>` | `/bc` | Рассылка во все активные каналы |

### Пользователи
| Команда | Алиас | Описание |
|---|---|---|
| `/channels` | `/ch` | Список активных каналов |
| `/report` | `/rep` | Пожаловаться на пост |

### Система
| Команда | Алиас | Описание |
|---|---|---|
| `/menu` | `/m` | Меню с кнопками управления (по роли) |
| `/hide` | | Скрыть клавиатуру меню |
| `/status` | `/st` | Статус системы |
| `/errors` | `/err` | Последние ошибки |
| `/logs` | `/log` | Файл логов |
| `/help` | `/h` | Справка |
| `/start` | | Приветствие |
| `/cancel` | | Отмена текущего диалога |

### Администрирование (только главный админ)
| Команда | Алиас | Описание |
|---|---|---|
| `/invite` | `/inv` | Создать инвайт-код временного админа |
| `/revoke <user>` | `/rev` | Отозвать права временного админа |
| `/ban <user>` | | Заблокировать пользователя (репорты) |
| `/unban <user>` | | Разблокировать |
| `/banned` | `/bans` | Список заблокированных |

`<user>` — числовой ID или `@username` (ник находится для тех, кто уже обращался к боту).

## 🧷 Интерактивный ввод параметров

Если команда требует параметр, а он не передан, бот переходит в режим ожидания и просит ввести значение. Это позволяет управлять ботом «в одно касание» (в т.ч. кнопками, которые просто отправляют команду).

```
Пользователь: /enable
Бот:          ❓ Вы не ввели ID пары. Введите его или отмените действие: /cancel
Пользователь: pair1
Бот:          ✅ Пара pair1 активирована!
```

- Ввод `/cancel` (или любой другой команды) отменяет ожидание.
- Поддерживается для: `/connect`, `/enable`, `/disable`, `/delete`, `/avatar`, `/backfill`, `/broadcast`, `/revoke`, `/ban`, `/unban`.

> На основе этого механизма реализовано **кнопочное управление**: `/menu` показывает reply-клавиатуру (кнопки под полем ввода), а нативная кнопка **Menu** — список команд. Кнопки действий с аргументом просто запускают интерактивный запрос параметра. Настройка кнопки Menu и списка команд в BotFather описана в [BOTFATHER_SETUP.md](BOTFATHER_SETUP.md).

## 📦 Как обрабатывается контент

| Тип | Поведение |
|---|---|
| **Текст** | Умное деление: основная часть в подпись (≤1024), остаток — ответами (≤4096, до 4 частей) |
| **Фото** | Одно — с подписью; несколько — альбом (до 10) |
| **Видео** | Скачивание через yt-dlp → MP4; альбомы; недоступные — ссылками |
| **Фото+видео** | Смешанный альбом одним сообщением |
| **GIF** | Анимация **с текстом в подписи — одним сообщением**; лишние GIF — ответом |
| **Аудио** | **Альбомом до 10 в одном сообщении**; недокачанные — ссылками |
| **Документы** | Загрузка и отправка; при недоступности — ссылка |
| **Статьи** | Превью + заголовок + ссылка (главное сообщение); прочее медиа — ответом |
| **Плейлисты** | Обложка + название + ссылка + число треков |

**Фильтрация постов:** игнорируются закреплённые, реклама (`marked_as_ads`), репосты (`copy_history`). Для пар с `is_safe=false` проверяются первые N комментариев — при наличии ссылки пост пропускается.

## 🏗️ Архитектура

```
main.py                 # точка входа: создаёт ЕДИНЫЕ экземпляры сервисов и внедряет их
config.py               # настройки (Pydantic), дефолты тюнящих параметров
handlers/
  auth.py               # /login, декораторы доступа
  admin.py              # /invite /revoke /ban /unban /banned
  user.py               # /channels /report
  system.py             # /start /help /status /errors /logs
  pair_management.py    # /connect /pairs /enable /disable /delete + верификация
  actions.py            # /backfill /broadcast
  avatar_management.py  # /avatar
  interactive.py        # запрос обязательных параметров (FSM) + /cancel
services/
  vk_service.py         # VK API (очередь запросов, retry)
  telegram_service.py   # отправка в Telegram (пер-канальный лимит, FloodWait)
  monitor.py            # цикл мониторинга, проверка рекламы, аватарки
  media_handler.py      # загрузка медиа (yt-dlp, фото, аудио, документы), кэш видео
  post_forwarder.py     # стратегии сборки и отправки поста
  storage_service.py    # БД + write-back кэш last_post_id
  queue_manager.py      # rate limiting (VK / per-channel Telegram)
  auth_service.py       # роли, инвайты, блокировки, @username
utils/
  messages.py           # все тексты ответов (единый источник)
  helpers.py            # форматирование, хэши, очистка, pad_cell для таблиц
  link_formatter.py     # ссылки (LRU-кэш пользователей)
  retry_helper.py       # стратегии повторов
  validators.py         # валидация VK-ссылок/ID и др.
  logger.py             # structlog + ротация + отправка критичных ошибок
database/
  models.py             # Pair, PairStats, User, InviteCode (Tortoise ORM)
  __init__.py           # init/close, постоянный админ
  migrate_db.py         # миграция старых БД (поля аватарок)
storage/bot.db          # SQLite
downloads/              # временные файлы
logs/bot.log            # логи
```

**Единые сервисы (DI):** `main.py` создаёт по одному экземпляру VK/Telegram/Storage/Media/PostForwarder/Monitor и передаёт их во все обработчики. Благодаря этому монитор и команды (например `/backfill`) разделяют общий кэш `last_post_id` — после досыла монитор продолжает с правильного места.

## 🔁 Надёжность и лимиты

- **Telegram:** пер-канальный лимит (сообщений/мин на чат) + обработка `TelegramRetryAfter` (ждём `retry_after`, повтор).
- **VK:** общая очередь запросов в секунду + retry на rate-limit (код 6).
- **Монитор (строгий режим):** retry с эскалацией; после исчерпания попыток пара останавливается, шлётся уведомление в `ERROR_CHANNEL_ID`, `last_post_id` не двигается.
- **`/backfill` (мягкий режим):** меньшие задержки, неудачные посты пропускаются с отчётом.
- **Lock-файл** (`.bot.lock`) — защита от двойного запуска.
- **Логи** — ротация по размеру/количеству; критичные ошибки дублируются в канал ошибок.

## 🔒 Безопасность

- Никогда не коммитьте `.env` (и `.env_old`/`.env.local`) — они в `.gitignore`. При утечке токенов **ротируйте** их (VK, BotFather) и чистите историю git.
- Главного администратора нельзя заблокировать; при старте с него снимается блокировка.
- Инвайт-коды генерируются криптостойко (`secrets`), действуют 24 ч, одноразовые.
- `verify_ssl=true` по умолчанию (проверка TLS); `false` — только для локальных тестов.
- Пользовательский ввод экранируется перед отправкой с `parse_mode=HTML`.

## 🛠️ Troubleshooting

**Бот не стартует** — проверьте токены в `.env`, удалите залипший `.bot.lock`, смотрите `logs/bot.log`.

**Посты не пересылаются** — пара активна? (`/pairs`), бот админ канала?, есть ли новые посты. Запуск: `/enable <pair_id>`.

**Видео не качается** — установлен ли `ffmpeg`, обновите `yt-dlp`, доступно ли видео публично.

**Большие файлы** — нужен локальный Bot API (`USE_LOCAL_API=true`), размер ≤ 2 ГБ.

**Аватарки не меняются** — бот должен быть админом канала с правом менять инфо. На старых БД выполните `python -m database.migrate_db`.

**Частые FloodWait** — увеличьте `MONITOR_INTERVAL`.
